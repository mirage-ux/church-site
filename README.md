# The Ministry of Faith / House of Hope — Website

This is the official website for **The Ministry of Faith / House of Hope**, led by Pastor Don Jones and Minister Barbara Jones in Houston, Texas.

Built with [Hugo](https://gohugo.io/) and hosted on GitHub Pages.

---

## How to Publish to GitHub Pages

1. **Create a GitHub account** at [github.com](https://github.com) if you don't have one
2. **Create a new repository** named `church-site`
3. Push this folder to that repository:
   ```
   git remote add origin https://github.com/YOUR-USERNAME/church-site.git
   git branch -M main
   git push -u origin main
   ```
4. In your GitHub repo, go to **Settings → Pages**
5. Under **Source**, select **GitHub Actions**
6. Your site will automatically build and go live at:  
   `https://YOUR-USERNAME.github.io/church-site/`
